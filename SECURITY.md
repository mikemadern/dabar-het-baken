# Beveiligingsbeleid

## Een kwetsbaarheid melden

Heb je een beveiligingsprobleem gevonden in deze website of in de code? Meld het dan **vertrouwelijk** via GitHub:

**[Een kwetsbaarheid melden](https://github.com/mikemadern/dabar-het-baken/security/advisories/new)**
(op de repository: tabblad *Security* → *Report a vulnerability*)

Je melding blijft zo privé totdat er een oplossing is. Maak voor een beveiligingsprobleem **geen** openbaar issue of pull request aan.

Beschrijf zo goed mogelijk wat je hebt gevonden, waar (pagina of bestand), hoe wij het kunnen nabootsen en wat volgens jou de impact is.

## Wat je kunt verwachten

Dit project wordt onderhouden door vrijwilligers. Daarom:

- We streven ernaar binnen **7 dagen** te reageren.
- We houden je op de hoogte van de voortgang en laten het weten zodra het is opgelost.
- We vragen je het probleem niet openbaar te maken voordat er een oplossing is. We stemmen dat samen met je af.
- Wil je in de oplossing genoemd worden? Laat het weten. Er is geen bugbounty of andere beloning.

## Welke versie

Alleen de actuele code op de `develop`-branch, en de website die daaruit wordt gepubliceerd, wordt bijgewerkt. Er zijn geen aparte releases of oudere versies met ondersteuning.

## Scope

**Binnen scope:** de code in deze repository (de Nuxt-website) en de afhankelijkheden daarvan.

De site is een voorlichtingswebsite zonder inlog, zonder eigen backend en zonder betalingsverwerking. Het contactformulier opent alleen het e-mailprogramma van de bezoeker.

**Buiten scope:**

- Websites en diensten die niet uit deze repository komen (bijvoorbeeld de oude site bakenharderwijk.nl, izb.nl, kriemelberg.nl, GitHub en de hostingdienst). Meld problemen daar bij de betreffende partij.
- Denial-of-service- of andere volume-aanvallen, spam, phishing of social engineering richting vrijwilligers.
- Geautomatiseerde scanrapporten zonder aantoonbare impact.

## Geen beveiligingsprobleem?

- **Bezwaar tegen een foto of video?** Zie de pagina *Fotobeleid* op de website.
- **Andere vragen?** Gebruik de pagina *Contact* op de website.

---

## English summary

If you found a security issue, please report it privately via GitHub (*Security* tab → *Report a vulnerability*) and do not open a public issue or pull request. This is a volunteer-run project: we aim to respond within 7 days, and there is no bug bounty. Only the current `develop` branch is supported.
